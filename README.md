# Добрый шкаф

Веб-приложение для передачи и повторного использования вещей: каталог вещей, организации и пункты приема, волонтерские задачи, личный кабинет пользователя, обмен сообщениями и экологический трекер.

## Требования

- **Node.js** 20+
- **npm** 10+
- Запущенный бэкенд API (по умолчанию `http://127.0.0.1:8000`)

## Переменные окружения

Скопируйте `.env.example` в `.env.local` в корне проекта:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

## Запуск в режиме разработки

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env.local` (см. выше).

3. Запустите бэкенд на порту **8000**.

4. Запустите фронтенд:

```bash
npm run dev
```

Сайт: [http://localhost:3000](http://localhost:3000).

## Структура проекта

```

```
